# 🥗 PrimeDieta

Aplicativo mobile voltado para organização de dieta e alimentação, desenvolvido como projeto de portfólio com foco em experiência mobile, navegação entre telas e persistência local de dados.

## 🚀 Tecnologias

- JavaScript
- React Navigation
- Expo SQLite
- Git e GitHub

## 💡 Objetivo do projeto

O PrimeDieta foi criado para praticar conceitos de desenvolvimento de aplicações mobile, organização de telas, navegação e armazenamento de informações localmente.

## 🧠 O que este projeto demonstra

- Estruturação de aplicação mobile
- Navegação entre telas
- Persistência de dados com SQLite
- Organização de dependências com npm
- Versionamento de código com Git

## 📦 Como executar

```bash
git clone https://github.com/JeanSmith011/Aplicativo-PrimeDieta.git
cd Aplicativo-PrimeDieta
npm install
npm start
```

> O projeto está em evolução e novas funcionalidades poderão ser adicionadas.
